# AWELJ Express Services Bootstrap Website

This ZIP contains two homepage options:

## 1. index.html — Pixel-match homepage
This is the closest possible match to the uploaded screenshot. It uses the screenshot as the visual base, with clickable hotspot links for navigation, quote, tracking, login, signup, and retailer boxes.

Use this if you want the public home page to look almost exactly like the image with very little work.

## 2. editable-index.html — Editable Bootstrap homepage
This is the normal Bootstrap 5.3 version built with editable HTML, CSS, and reusable sections.

Use this if you want your developer to edit text, move sections, replace images, or connect the page to a backend.

## How to run in VS Code
1. Open the folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Choose `Open with Live Server`.

## Important note
The exact visual design in `index.html` is based on the screenshot. If you need every item to be fully editable while also remaining pixel-perfect, you need the original source design files or separate assets: logo, plane, truck, ship, package boxes, map pins, retailer logos, and background images.
